## CRUD con JSON: Mi agenda deportiva

Proyecto Java para Apache NetBeans con atributos `static` y `transient`,
referencia a un deportista y lista de entrenamientos. Incluye creación,
lectura, actualización, append y borrado con persistencia JSON.

- [Proyecto e instrucciones](EntrenamientosCRUD/README.md)
- [Proyecto completo en ZIP](Entregas/EntrenamientosCRUD.zip)
- [Informe de ejecución en PDF](EntrenamientosCRUD/Informe_ejecucion.pdf)
- [JSON final obtenido](EntrenamientosCRUD/datos/demo/planes.json)
- [Clases Java utilizadas](EntrenamientosCRUD/src/main/java/es/ficheros/deportes)

Verificado en Apache NetBeans IDE 27 con JDK 24.0.2. Requiere Java 17 o superior.
Las 12 pruebas JUnit finalizaron sin fallos ni errores.

## XML DOM: datos del ejercicio 11

Proyecto Java para Apache NetBeans que reutiliza las clases `PlanDeportivo`,
`Deportista` y `Entrenamiento` del CRUD para generar un archivo XML mediante DOM.
Incluye dos planes, dos deportistas y tres entrenamientos; conserva UTF-8 y
comprueba la lectura del archivo generado.

- [Proyecto e instrucciones](XMLDOM/README.md)
- [Proyecto completo en ZIP](Entregas/XMLDOM.zip)
- [Informe de ejecución en PDF](XMLDOM/Informe_ejecucion.pdf)
- [Archivo XML obtenido](XMLDOM/datos/planes.xml)
- [Clases Java utilizadas](XMLDOM/src/main/java/es/ficheros)

Verificado con Apache NetBeans IDE 27 y JDK 24.0.2. Requiere Java 17 o superior.
Las seis pruebas JUnit finalizaron sin fallos ni errores.
